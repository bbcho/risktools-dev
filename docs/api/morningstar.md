# Morningstar API

Functions for fetching commodity prices and forward curves from the Morningstar
Commodities data API.

## Prices

::: risktools.get_prices
    options:
      show_root_heading: true
      heading_level: 3

## Forward Curves

::: risktools.get_curves
    options:
      show_root_heading: true
      heading_level: 3
