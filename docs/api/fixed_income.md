# Fixed Income & Derivatives API

Functions for bond pricing, net present value, options pricing, interest rate
swap valuation, and commodity swap analysis.

See the [Fixed Income Guide](../guides/fixed_income.md) for bond pricing theory and
the [Options Pricing Guide](../guides/options_pricing.md) for the CRR binomial model.
